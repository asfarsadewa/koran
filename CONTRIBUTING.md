# Contributing

Juara Merdeka is published for source inspection and security review. It is not currently accepting unsolicited code contributions.

Please do not open a pull request without discussing the proposed change with the maintainer first. Public issues may be used for ordinary defects and documentation questions after the repository becomes public. Report security problems privately according to [`SECURITY.md`](SECURITY.md).

The repository is not open source. A contribution does not grant a license to use the existing code, nor is it accepted under a separate contribution license unless the maintainer agrees to those terms in writing.
