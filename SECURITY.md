# Security policy

## Supported version

Only the current `main` branch and the production deployments at `koran.r3ptil.com` and `juara-merdeka-agent.vercel.app` are supported.

## Report a vulnerability

Do not open a public issue or pull request for a suspected vulnerability.

After this repository becomes public, use GitHub's private vulnerability reporting form under **Security → Advisories → Report a vulnerability**. Include:

- the affected route, component, or commit;
- steps to reproduce the problem;
- the likely impact;
- any suggested mitigation;
- whether the finding has been disclosed elsewhere.

While the repository remains private, send the same information to the maintainer through an existing private channel. Do not include live credentials, personal data, or exploit traffic beyond what is necessary to demonstrate the problem.

There is no guaranteed response time. The maintainer will acknowledge and assess reports as availability permits, and will coordinate disclosure when a fix is ready.
